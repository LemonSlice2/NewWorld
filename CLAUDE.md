# NewWorld — текстовая ролевая игра

Славянское тёмное фэнтези на сломе эпох: 1929 год, старое ещё живо, новое
уже приехало с мандатом. Автор игры — Николай (Коля), не программист:
объяснять решения нужно словами, а не терминами, и показывать, что
изменилось для игрока.

## Несущее решение

**Движок возвращает факты, а не текст.** Ход игрока превращается в список
событий (`CheckRolled`, `ItemGained`, `DamageTaken`), а описывает их
отдельный слой — рассказчик. Поэтому правила проверяются тестами, а
оболочку можно менять, не трогая игру.

Оболочек уже три, и ядро у них общее:

```
newworld/core/      правила: кубы, состояние, сюжет, движок
newworld/narrator/  факты -> текст (шаблонный; сюда же встанет нейросетевой)
newworld/storage/   сохранения (SQLite)
newworld/bot/       Telegram
newworld/desktop/   окно на компьютере (Qt)
newworld/cli.py     терминал
content/            сюжеты (YAML)
assets/             картинки (полоса здоровья)
tools/              вспомогательные скрипты
```

Добавляя новую оболочку, **не дублируй правила**: бери `Engine`,
`Narrator` и `GameState` как есть.

## Команды

```bash
python -m newworld.desktop content/olhovets.yaml  # играть в окне
python -m newworld.cli content/olhovets.yaml     # играть в терминале
python -m newworld.bot content/olhovets.yaml     # Telegram (нужен .env)
python -m pytest                                  # все тесты
python tools/slice_health_bar.py assets/raw/*.jpg --fill   # нарезать картинки
```

## Правила работы с этим проектом

**Сюжет пишется в YAML, код для этого трогать не нужно.** Формат описан в
README. Загрузчик строго проверяет файл: ссылка на несуществующую сцену,
неизвестный эффект или сцена-тупик должны падать при старте с понятным
сообщением автору, а не у живого игрока.

**Выбор игрока обязан что-то менять.** Специализация, которая не
открывает ни одного действия, — просто цифры. На это есть тест: флаги
каждого сочетания класса и специализации должны где-то в сюжете
требоваться.

**Род в тексте.** Русский показывает род в прошедшем времени, поэтому
пишется развилка по месту: `Ты выш{ел|ла} наверх`. В настоящем времени
(«ты знаешь») развилка не нужна. Тест ищет места, где род виден, а
развилки нет.

**Баланс проверяется прогоном, а не на глаз.** Тесты гоняют сотни
случайных забегов каждой сборкой и требуют, чтобы смертность держалась
ниже половины, а каждая сборка доходила до концовки. Меняя урон или
характеристики, прогоняй их.

**Ограничения Telegram, которые уже учтены** (не сломай при правках):
одно сообщение на сцену — оно перерисовывается, а не дублируется (лимит
частоты сообщений в чат); в `callback_data` лежит адрес действия, а не
описание (64 байта); кнопка из прокрученного вверх сообщения не
срабатывает повторно (сверяется номер хода); подпись к фото — 1024
символа, поэтому картинка есть только в карточке персонажа.

**Тесты — часть работы, а не отчётность.** Сквозной тест
(`tests/test_bot_flow.py`) прогоняет путь живого игрока через настоящий
Dispatcher с подставной сетью: молчащий бот должен ловиться тестом, а не
в переписке.

## Секреты

Токен бота живёт в `.env` (в репозиторий не попадает) или в переменной
`NEWWORLD_BOT_TOKEN`. В коде, сюжете и коммитах его быть не должно.

## Язык

Весь текст — русский: и сюжет, и сообщения бота, и комментарии в коде, и
сообщения коммитов. Комментарии объясняют **почему** так сделано, а не
пересказывают код.
