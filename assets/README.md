# Картинки

## `health/` — полоса здоровья

Нарезанные состояния полосы: `health-0.png` — все ячейки погасли,
`health-9.png` — все горят. Номер в имени и есть уровень; сколько их
всего, бот определяет сам, пересчитывая здоровье в долю от максимума.

Живой герой никогда не показывается пустой полосой, а мёртвый — непустой:
по картинке должно быть сразу понятно, жив он или нет.

Картинки показываются в карточке персонажа (`/status`). Под каждым ходом
их нет намеренно: Telegram ограничивает подпись к фото 1024 символами, а
описания сцен длиннее — пришлось бы резать текст.

Набор необязателен. Нет папки или в ней меньше двух файлов — бот рисует
полосу символами и работает как прежде.

## `raw/` — исходные листы

Картинки, как их выдал генератор: листами, где состояния идут рядами.
Исходники лежат в репозитории, чтобы перенарезать при смене стиля.

Текущий набор собран так:

```bash
python tools/slice_health_bar.py assets/raw/sheet-1.jpg assets/raw/sheet-4.jpg --fill
```

`sheet-1` — бронзовая панель с горящими ячейками, `sheet-4` — она же
пустая. Генератор выдаёт состояния не подряд: на листе есть 1-4 и 6-9, а
пятёрки нет вовсе. Ключ `--fill` достраивает пропуск из соседнего
состояния, переставляя ячейки внутри той же картинки, — подсветка и фон
при этом совпадают, стыка не видно.

`sheet-2` и `sheet-3` — тот же индикатор в тёмно-сером исполнении, без
бронзы. Если захочется сменить стиль, набор пересобирается из них той же
командой.
