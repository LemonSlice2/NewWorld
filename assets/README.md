# Картинки

## `health/` — полоса здоровья

Нарезанные состояния полосы: `health-0.png` — все ячейки погасли,
`health-9.png` — все горят. Номер в имени и есть уровень; сколько их
всего, бот определяет сам, пересчитывая здоровье в долю от максимума.

Живой герой никогда не показывается пустой полосой, а мёртвый — непустой:
по картинке должно быть сразу понятно, жив он или нет.

Картинки показываются в карточке персонажа (`/status`). Под каждым ходом
их нет намеренно: Telegram ограничивает подпись к фото 1024 символами, а
описания сцен длиннее — пришлось бы резать текст.

Набор необязателен. Нет папки или в ней меньше двух файлов — бот рисует
полосу символами и работает как прежде.

## `raw/` — исходные листы

Сюда кладутся картинки, как их выдал генератор: листами, где состояния
идут рядами. Из них нарезается `health/` скриптом
`tools/slice_health_bar.py`. Исходники держим в репозитории, чтобы
перенарезать при смене стиля, не выпрашивая файлы заново.
